[Peers Touch](https://github.com/peers-labs/peers-touch) 是我从 0 到 1 发起并主导的项目。今天的社交网络把用户的关系与数据锁在中心化服务器上：隐私让渡给平台，账号也未必真正属于自己。Peers Touch 想给出另一种答案——点对点、可自托管的联邦网络，社交关系和数据归用户所有。而 AI Agent 是这个时代的新生事物，而市面上的 Agent，本质上还是互联网巨头的产品延伸，所以，我们也在尝试做自己的 Agent 能力，让它跑在用户自己的节点上，而不是平台提供的一项服务。这件事分两步走：第一步，在去中心化的地基上搭建社交网络本身；第二步，在 AI 时代，让个人的社交基因具备 Agent Native 的扩展能力。
